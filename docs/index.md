# Bun RAD Studio handbook

**Documentation scope:** written against the repository at commit `2f8d2f9` (13 October 2026), checked on macOS (Apple silicon) with Bun 1.4.2. Anything not checked on that setup is labelled *not verified*. This handbook is **being built in phases**; the [coverage matrix](documentation-maintenance/coverage-matrix.md) shows exactly what is and is not documented yet.

## What the project is

Bun RAD Studio is a collection of desktop-style tools written in TypeScript and run with Bun (a program that runs JavaScript and TypeScript code). Windows are drawn with a Webview, which is a small browser window embedded in a normal desktop window. The repository contains:

- a **launcher** that finds and starts every other tool,
- **70 studios** (windowed applications: database tools, developer tools, system tools, games and more),
- **78 command-line tools** and **27 demos**,
- a **visual form designer** (the "IDE") for laying out forms,
- the **SimpleGUI** library for writing windows in code,
- a shared **Database Workbench** for MySQL, PostgreSQL and SQLite.

The counts come from the launcher's own scan (`bun run cli:launcher --list`); see the [application index](reference/application-index.md).

## Important limitations (read before relying on anything)

- **The visual designer is only partly verified.** It had three defects that made it unusable ([D-001](documentation-maintenance/discrepancies.md#d-001), [D-016](documentation-maintenance/discrepancies.md#d-016), [D-017](documentation-maintenance/discrepancies.md#d-017)); all are fixed. Placing controls, the property fields, the code tabs, undo/redo, Audit and Import were checked in a browser rendering of the page. Run, Export and the native window were not, and the designer page says which is which.
- **Designer database controls are placeholders** that show sample rows; they are not connected to a database ([D-002](documentation-maintenance/discrepancies.md#d-002)).
- **Only macOS was used for hands-on verification.** The automated tests also run in CI on Linux (all pass) and Windows (31 of 1,400 fail, which looks like Unix-only assumptions but was not diagnosed test by test), but no window was opened there by hand ([Testing](testing/index.md#other-platforms), [requirements](getting-started/requirements.md#operating-systems)).
- **Older per-application guides** in `docs/userguides/` were generated by a script and have **not** been checked against the code ([D-004](documentation-maintenance/discrepancies.md#d-004)).
- Planned features (import wizard, MySQL/PostgreSQL backup, generated database-backed apps, …) are listed as *Planned* and are not available.
