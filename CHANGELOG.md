# Changelog

All notable changes. The project has no versioned releases yet, so everything is under **Unreleased**. Each entry points to the record of what was observed and how it was checked in [discrepancies](docs/documentation-maintenance/discrepancies.md). History before 13 October 2026 is only in git.

## Unreleased (13 October 2026 review)

### Added

- **File Manager: copy any section.** Every block of information (a group in *Properties* or *More info*, the Details panel, a table, a list of facts, a log, a result, an error message, Help and About) gets a small **Copy** button next to its heading that copies just that block as clean text; the **▾** beside it also offers a table for spreadsheets, Markdown or JSON, and **Alt+Shift+C** (⌥⇧C on a Mac) copies the section you are in. In the **Crypto** tab each digest row, log entry, generated password, key or UUID, converted text, token part and check result can be copied on its own, each card has a Copy, and **Copy all** copies the tab (never what you typed); this replaces the separate *Copy digests* and *Copy password* buttons, and secrets keep the "other programs can read the clipboard" reminder. Pop-up errors have **Copy error**. See [the guide](docs/userguides/43_file_manager.md#copy-any-section).
- **File Manager: live server and PHP server (Serve tab).** Find & more → **Serve**, right-click a folder → *Start live server here* / *Stop live server* (and *Start PHP server here* / *Stop PHP server* for a PHP project), right-click an HTML file → *Open with live server*, and a Home tile. The **live server** is built in (Bun's own server, no extra program): read only, safe paths (no `..`, no symlink escapes, hidden files and `.git` never shown), correct types for about 100 file extensions, `Range` requests, `ETag`/304, a folder list or its `index.html`, `127.0.0.1` only with a Host-header check, and **automatic reload** over server-sent events (CSS-only changes swap the styles). The **PHP server** runs `php -S` with an argument list, a minimal environment, a log, a readiness check and a SIGTERM-then-SIGKILL stop (nothing is installed for you; install hints are shown). Up to 8 servers, a list with on/off switches, *Open in browser*, *Copy URL*, *Restart* and logs, a **● Live :5500** pill in the status bar, and an opt-in **LAN** mode that asks first and is never remembered. See [the guide](docs/userguides/43_file_manager.md#live-server-and-php-server-serve-tab).
- **File Manager: theme editor.** Create your own themes or start from any of the 135 and change them: colour pickers and hex codes for the window, panels, text, accent, lines and status colours, a live preview in the whole window, automatic readability fixes with an explanation, up to 50 saved themes in a **My themes** group, plus Export and Import as text (ops `themes/preview`, `themes/custom/save`, `delete`, `export`, `import`; file `file_manager_themes.json`).
- **File Manager: 135 colour themes.** Settings → *Choose a theme…* or the Home tile **Themes** opens a searchable gallery (Futuristic, Editors and classics, Linux, Windows, macOS; light and dark filter) that applies a theme live and remembers it (new setting `palette`, ops `themes/list` and `themes/get`). Colours come from the SimpleGUI theme table and are adjusted until all 135 pass the same contrast pairs as the built-in light and dark colours.
- **Futuristic themes and a motion layer.** Twelve new themes (Cyberpunk Hologram, Neon HUD, Quantum Obsidian, Deep Space, Liquid Metal, Titanium Aurora, Liquid Metal Light, Neo-Tokyo Dark, Synthetic Solar, Neo-Tokyo Day, Aurora Glass, Plasma Violet; 133 themes in all) with an optional `fx` descriptor on `SimpleGUITheme`: glass surfaces, edge glow, a gradient or metal ring, a slow backdrop, scanlines, chromatic headings, and a compositor-only motion layer (button bloom and press, floating labels, sliding tab indicator, tilting cards, row accent bar, modal and sheet entry with staggered children, live pill, pulse dot, skeleton). Everything is scoped under `data-fx="on"` (also `reduced` and `off`), honours reduced motion, higher contrast and forced colours, and themes without `fx` are byte-identical to before. `getThemeFx()`, `isFxTheme()`, `fxCssVars()` and `getSyntaxPalette()` are exported; `createWindow(..., { effects })` and `win.setEffects()` switch effects. The Visual Designer has a **Futuristic** theme group and an **Effects** control (Full, Reduced, Off) that is saved with the form, and the canvas previews the effects. New: `design_tokens.css` token set and drop-in classes, `bun run fx:build` / `fx:check`, [developer guide](docs/developer/fx-themes.md), gallery in [THEMES.md](docs/THEMES.md#fx-themes). See [D-054](docs/documentation-maintenance/discrepancies.md#d-054).
- **File Manager code editor: Autosave you can see and tune.** A status-bar toggle, **View → Autosave options…** (delay from 0.5 to 30 s, optional save when you switch away), an **Autosaved** indicator, settings `autosaveDelay` and `autosaveOnBlur`. Autosave never overwrites a file that changed on disk.
- **File Manager: About and GitHub links.** Help → *About and GitHub* and a Home tile open a window with the project on GitHub, the issue tracker, releases, the author's profile and the donation page. The page sends only a link id; the addresses are fixed on the server (`about/info`, `about/open`), which opens them in the default browser.
- **File Manager: `.v` and about 55 other source-code extensions** (V, Zig, Nim, Elixir, Haskell, OCaml, Julia and more) are shown as source files with a text preview; V files are labelled "V source file".
- **File Manager: More info and metadata.** Alt+Shift+Enter, right-click → *More info…*, or the button in Properties and the Details panel opens a searchable, copyable window of grouped details for a file, picture, folder or selection: real kind from the first bytes, MIME, size on disk, permissions, macOS origin (where-from, quarantine, tags, signature summary), and built-in readers for **pictures** (PNG, JPEG, GIF, WebP, BMP, ICO, TIFF, HEIC/AVIF, SVG with a safe parse; EXIF in both byte orders with GPS, ICC, XMP, a quality estimate, a colour palette worked out in the page), **sound and video** (ffprobe when installed, else MP3, WAV, FLAC, Ogg, MP4/MOV, MKV/WebM), **documents** (PDF, Office, OpenDocument, EPUB, zip/tar/gz with zip-bomb caps, SQLite, fonts, text and JSON, PE/ELF/Mach-O headers), fingerprints (MD5, SHA-1, SHA-256, SHA-512, CRC32 with progress, Cancel and a forgiving Compare) and an optional ExifTool list. A privacy summary warns when a photo holds its location and offers **Remove private info…**, a lossless built-in cleaner for JPEG, PNG and WebP that makes `<name> (no metadata).<ext>` and never touches the original; the map link opens only after a confirmation. Reports can be copied or saved as text, JSON or Markdown next to the file. The Details panel shows a compact Photo strip and a "Has location" badge. New operations `info/…`; about 190 new tests built on real byte-accurate files, ExifTool, ffprobe, ImageMagick and `lipo` where installed. macOS only was run; the Linux and Windows extras are not verified.
- **File Manager: Dev tab** (Find & more → Dev, or right-click a folder → **Code statistics…**). Developer information about a folder, all read only: **code statistics** (a "tokei studio": lines of code, comments and blanks per language with the real `tokei` when it is installed or a built-in counter for 100+ languages including V, sortable table, share bar, per-language file drill-down, export as CSV/JSON/Markdown, and snapshots to compare later); a **project overview** (Node/Bun scripts with ▶ Run in terminal, Rust, Go, Python, V, Java/Kotlin, .NET, PHP, Ruby, Swift, C/C++, Docker, CI, licence type; `.env` names only); a **Git summary** (remote passwords removed); **disk & files** (size breakdown, heavy folders with Move to Recycle Bin, duplicates); a **TODO/FIXME** scanner; and the **developer tools** installed. tokei is optional (`brew install tokei` or `cargo install tokei`). Scans never follow links and stop at 200,000 files or 60 seconds. See [File Manager](docs/userguides/43_file_manager.md#developer-information-dev-tab).
- **File Manager: files that aren't what their name says.** Reads the first 600 bytes of listed files and badges a program called `invoice.pdf`, a PNG called `photo.jpg`, `report.pdf.exe` and names with a right-to-left override, hidden characters, padding or a trailing dot (**Danger**, **Warning**, **Note**), with a plain explanation, a safe *Rename to .png*, and a confirmation before opening a dangerous one (also through *Open with…*); new `check/files` and `check/one` operations, `TYPE_MISMATCH` (HTTP 409) and the setting `typeWarnings`. Tests: `tests/file_manager_sniff.test.ts`, `tests/file_manager_typecheck_page.test.ts`.
- **File Manager: favorite places.** A ★ in the address bar adds or removes the current folder; the sidebar section, a ⭐ toolbar menu and Ctrl/⌘+Shift+B jump to them; *Manage favorites* renames, reorders, removes and adds (typed paths, `~`), marks folders that are gone, up to 100 (new setting `favoriteNames`).
- **File Manager: password encryption of files and folders (RADENC v1).** Toolbar **Lock**, right-click → **Encrypt…** / **Decrypt…**, and Enter on a `.radenc` file. Argon2id (256 MiB, or 1 GiB at Maximum) → HKDF → AES-256-GCM in 1 MiB authenticated chunks, streamed with constant memory, checked after writing, never overwriting, with an optional move of the original to the Recycle Bin. Includes a passphrase suggester, a strength meter, `bun run cli:vault` (`encrypt`, `decrypt`, `info`; password from a prompt, a file or `RADENC_PASSWORD`), a [byte-exact format document](docs/reference/vault-format.md) and a [security model](docs/security.md#file-encryption-radenc).

- **File Manager: Code editor** (Find & more → Code, right-click → Edit in Code editor, or Ctrl/Cmd+E). A built-in editor with tabs, a folder tree, find and replace, find in files, Git changes, outline, bookmarks, Markdown and HTML preview, themes, safe saving (BOM/UTF-16/line endings kept, stale-on-disk check, atomic writes), session restore, code completion with snippets and signature tips for 17 language families, per-file **Run and Build presets** that type into the built-in Terminal, and first-class **V (vlang 0.5.2)** support including `v fmt` formatting. API: `code/*` (see `fmCodeOps.ts`).
- **File Manager: workspace views.** Five views you can switch between at the top of the window — **Files**, **Home** (a start page with a tile for everything the app can do, pinned folders, drives, recent files, quick actions, tips and helper-program status), **Tools** (the Power tools with the whole window, tabs now grouped and scrollable), **Split** (files beside a tool, side by side or stacked, with a keyboard-resizable divider) and **Dual** (two folders; F5 copy, F6 move, Tab to switch side, drag between them; the right pane is lighter than the left) — plus **Focus** (hide toolbar and side panels) and a foldable sidebar. Keys: Alt+1…5 (⌥ on a Mac) for the views, Alt+6 Focus, Alt+7 sidebar. The toolbar keeps to one row with a **More** menu, and the status bar has Details/List/Icons buttons. The view, split direction and size, sidebar, Focus and last tools are saved (new settings `workspace`, `startWith`, `splitSide`, `splitSize`, `sidebarCollapsed`, `focusMode`, `activeTool`, `splitTool`, `dualPath`). Also fixed: Enter and Space on a focused button no longer get swallowed by the file list's shortcuts. See [File Manager](docs/userguides/43_file_manager.md#views).
- **Release builds for every platform** (`bun run release:build`): one archive per platform and processor (macOS arm64/x64, Linux x64/baseline/arm64 and musl, Windows x64/baseline/arm64) with all 73 desktop apps and 78 command-line tools, `SHA256SUMS.txt` and generated release notes, ready for `gh release create`. See [Building releases](docs/developer/releasing.md) and D-053.
- **Mac apps with their own icons** (`bun run build:mac-apps`): every desktop app as a signed, self-contained `.app` with its own glass-style icon (an SF Symbol or a drawn shape chosen for the app, in its category's colours).
- **45 new themes (121 in all)**: 28 Linux distributions, desktop environments and GTK themes (Debian, Arch, openSUSE, Manjaro, elementary, Kali, Zorin, RHEL, Rocky, Alma, CentOS, Fedora Light, EndeavourOS, NixOS, Gentoo, Alpine, KDE Breeze, Xfce, MATE, Deepin, Arc, Sweet, Numix), 11 Windows versions (3.1, 98, 2000, XP, Vista, 7, 8, 10, Terminal, High Contrast) and 7 macOS versions (Mac OS 9, Snow Leopard, Yosemite, Big Sur, Monterey, Sequoia, Tahoe). Gallery: `docs/THEMES.md` (generated block, `bun run scripts/build_os_theme_docs.ts`). See D-052.
- **Status colours (danger, warning, success, info)** for every theme: `getSemanticColors(theme)`, CSS variables `--danger`, `--danger-on`, `--danger-text`, `--danger-soft`, `--danger-border` (and the same for the other three), button `variant: "danger" | "warning" | "success" | "info"` with `appearance: "soft" | "outline"`, and badges, alerts, toasts, status dots and count badges that use them. Contrast is checked for all themes by `tests/theme_semantic.test.ts`.
- **`LICENSE` (MIT, © 2026 Jerome Scott)** and `"license": "MIT"` in `package.json`. The README already declared MIT and its badge linked to a `LICENSE` file that did not exist. Licenses of bundled third-party assets were not audited.
- `SECURITY.md` (how to report a problem and what is in scope) and this changelog.

- **File Manager** (`bun run app:files`): an easy file manager for macOS, Windows and Linux with a sidebar, breadcrumb address bar, three views, search, drag and drop, a details panel with previews, bulk rename, zip and extract, favorites, an undoable Recycle Bin and full keyboard use. Verified on macOS only; Windows and Linux windows and open commands are **not** verified ([guide](docs/userguides/43_file_manager.md), [D-045](docs/documentation-maintenance/discrepancies.md#d-045)).

- **The file list follows the terminal**: when you `cd` in the File Manager's terminal, the list above moves to that folder (tick **Follow terminal** to turn it off; the choice is remembered). Verified in a real browser and with tests over a real shell.
- **File Manager terminal** (toolbar button or Ctrl+`): a real shell at the bottom of the window, started in the folder on screen, with **Go to this folder** and **Restart**. macOS and Linux; a button that is greyed out on Windows. Adds the vendored xterm.js (MIT) library ([D-046](docs/documentation-maintenance/discrepancies.md#d-046)).

- **File Manager: Convert & process.** Right-click pictures, videos, sound or documents to convert, shrink, rotate, combine into a PDF and more, in batches, using ImageMagick, ffmpeg and pandoc (including the Homebrew `-full` builds, found even when they are not on the PATH). A tasks panel shows progress and lets you cancel. If a program is missing the window says so and offers an Install button (Homebrew, winget, Scoop) or the exact command to copy or type in the Terminal. `bun run tools:check` and `bun run tools:install` do the same from a terminal ([D-048](docs/documentation-maintenance/discrepancies.md#d-048)).

- **Tooltips for every non-game app:** hover over (or tab to) any button, field, select or tab to read what it does. About 2,200 hand-written tips for 38 windows, one dictionary per app, with a test that fails when a control has none ([D-049](docs/documentation-maintenance/discrepancies.md#d-049)). The authors of the tips also reported defects they found in the apps; they are listed, unfixed, in [D-050](docs/documentation-maintenance/discrepancies.md#d-050).
- **`SHOWCASE.md`:** a picture-led page presenting all 65 applications, generated from their screenshots; 20 applications that had no screenshot now have one, including the File Manager (preview, Convert window and terminal). New start commands `bun run app:redis`, `app:pipe` and `app:subprocess`, which did not exist ([D-051](docs/documentation-maintenance/discrepancies.md#d-051)).

### Behaviour changes to know about

- **Library server helpers listen on `127.0.0.1` by default.** `serveStatic` and `createWsHub` (RAD `serverutils`) and `Sys.serve` / `Sys.serveStatic` (SimpleCLI) used to listen on all network interfaces. Pass `hostname` (for example `"0.0.0.0"`) to expose a server on purpose ([D-037](docs/documentation-maintenance/discrepancies.md#d-037)).
- **Designer keyboard and dialogs:** Enter or Space on a palette item now places the control; Alt + arrows resize; Escape closes any dialog; editing shortcuts are ignored while a dialog is open ([D-035](docs/documentation-maintenance/discrepancies.md#d-035), [D-036](docs/documentation-maintenance/discrepancies.md#d-036)).
- **Designer autosave:** the open form is copied to `~/.bun_rad_studio/designer_draft.json` after each change, and a banner offers to restore it on the next start ([D-039](docs/documentation-maintenance/discrepancies.md#d-039)).
- **Export keeps your edits:** a generated file that would change is first kept as `<name>.bak-<time>` ([D-022](docs/documentation-maintenance/discrepancies.md#d-022)).
- **Import** warns before loading a layout that contains event scripts ([D-024](docs/documentation-maintenance/discrepancies.md#d-024)).

### Security

- Every studio HTTP server binds to loopback and refuses foreign `Origin` and `Host` headers; a test fails if a new `Bun.serve` has no `hostname` or no guard ([D-012](docs/documentation-maintenance/discrepancies.md#d-012), [D-013](docs/documentation-maintenance/discrepancies.md#d-013), [D-037](docs/documentation-maintenance/discrepancies.md#d-037)).
- Code Studio no longer runs commands for any web page.
- Crafted layouts can no longer inject code through titles, sizes or other generated-code fields ([D-021](docs/documentation-maintenance/discrepancies.md#d-021)); the Audit report escapes ids and the form title ([D-041](docs/documentation-maintenance/discrepancies.md#d-041)).
- A test-only package (`jsdom`) moved out of runtime dependencies; `bun audit` is clean ([D-029](docs/documentation-maintenance/discrepancies.md#d-029)).

### Fixed

- **File Manager: a stray "null" next to Properties.** Selecting a file without a "Edit in Code editor" button (a PDF, picture, zip, sound...) showed the word *null* after the buttons in the Details panel, because a missing part was passed to `append`, which prints it. The same slip was in the Dev tab's TODO list when nothing was cut off. `tests/file_manager_info_panel.test.ts` checks every kind of selection.
- **Linux themes:** list boxes, sliders and pickers could be unreadable in dark themes, and switching themes while a window was open left old inline surface colours (unreadable text on every OS) ([D-047](docs/documentation-maintenance/discrepancies.md#d-047)).
- `bun start` crashed at launch ([D-001](docs/documentation-maintenance/discrepancies.md#d-001)); the designer page's script was cut short so the page did nothing, and its Import, Keys and Audit dialogs could never appear ([D-016](docs/documentation-maintenance/discrepancies.md#d-016), [D-017](docs/documentation-maintenance/discrepancies.md#d-017)).
- Exported projects did not parse ([D-011](docs/documentation-maintenance/discrepancies.md#d-011)); Import could corrupt the open form ([D-018](docs/documentation-maintenance/discrepancies.md#d-018)).
- Run only worked from the project folder ([D-023](docs/documentation-maintenance/discrepancies.md#d-023)); Frogger, Snake and Tetris only started from the repository root ([D-038](docs/documentation-maintenance/discrepancies.md#d-038)). Run now keeps the preview's output in `.rad_preview/preview.log` and shows failures in the status bar ([D-040](docs/documentation-maintenance/discrepancies.md#d-040)).
- The launcher listed library files as applications ([D-014](docs/documentation-maintenance/discrepancies.md#d-014)); the Redis studio crashed when started directly ([D-015](docs/documentation-maintenance/discrepancies.md#d-015)).
- Real defects found while removing 679 type errors, such as the PostgreSQL dump header, game window titles and the unified `src/index.ts` exporting undefined names ([D-026](docs/documentation-maintenance/discrepancies.md#d-026), [D-027](docs/documentation-maintenance/discrepancies.md#d-027)).

### Accessibility (designer page only)

- Visible keyboard focus, a keyboard-reachable palette, readable button contrast in every theme ([D-031](docs/documentation-maintenance/discrepancies.md#d-031), [D-019](docs/documentation-maintenance/discrepancies.md#d-019)); component Tree rows can be selected (also as ranges) from the keyboard ([D-035](docs/documentation-maintenance/discrepancies.md#d-035)). Not tested with a screen reader. Details: [Accessibility](docs/accessibility.md).

### Developer and project health

On Linux, **Copy no longer stalls** when `xclip` or `wl-copy` is installed, and the type-check ratchet and docs generator are portable.

- A macOS CI workflow (type-check ratchet, documentation check, tests); the type-error baseline is 0 ([D-020](docs/documentation-maintenance/discrepancies.md#d-020), [D-032](docs/documentation-maintenance/discrepancies.md#d-032), [D-033](docs/documentation-maintenance/discrepancies.md#d-033)).
- Tests no longer depend on the author's machine: Redis, MySQL, PostgreSQL and live-network tests are opt-in ([D-032](docs/documentation-maintenance/discrepancies.md#d-032)); generated files are no longer tracked or modified by test runs ([D-006](docs/documentation-maintenance/discrepancies.md#d-006), [D-025](docs/documentation-maintenance/discrepancies.md#d-025), [D-030](docs/documentation-maintenance/discrepancies.md#d-030)).
- **The designer page is edited as 23 parts in `src/ide/`** and built into the (still committed, byte-identical) `src/ide.html` with `bun run ide:build`; `bun run ide:check` and a CI step catch drift. Refactor only ([D-044](docs/documentation-maintenance/discrepancies.md#d-044)).
- 14 game servers now share `src/studio_server.ts` (−924 lines, no behaviour change) ([D-034](docs/documentation-maintenance/discrepancies.md#d-034)).
- A documentation handbook under [docs/](docs/index.md) with an automated link and command check; open and unverified items are listed in [discrepancies](docs/documentation-maintenance/discrepancies.md) and the [risk register](docs/documentation-maintenance/baseline-and-risks.md).
